Reproducing and exploring this work

Every result on this site traces back to a numbered notebook. They are listed in the order they run, followed by what you need to reproduce them and how to cite the work.

Notebooks

  1. 01

    data_pipeline

    Manifest construction, session grouping, splits and the trimodal data loaders shared by every later notebook.

  2. 02

    dataset_analysis

    TR-6 composition, missingness, class balance and per-produce target distributions. Source for the Dataset page.

  3. 03

    encoders_baselines

    CBAM visual encoders and the GRU-D gas encoder, developed and checked on their own.

  4. 04

    fusion_model

    The full trimodal model, ten-seed training, ensembling, threshold calibration and the headline test result.

  5. 05

    ablation_study

    Seven-configuration ablation: four component ablations and two fusion baselines.

  6. 06

    bootstrap_significance

    Paired bootstrap significance tests for the ablation.

  7. 07

    backbone_benchmark

    Eight-candidate sRGB backbone comparison, including a frozen DINOv2.

  8. 08

    missing_data_robustness

    F1 under simulated sRGB, thermal, gas and joint sensor dropout on validation and test.

  9. 09

    lofo_generalization

    Six-fold leave-one-fruit-out generalisation test.

  10. 10

    explainability

    Grad-CAM on the visual encoders, SHAP on the gas features and cross-modal attention weights.

  11. 11

    uncertainty_quantification

    Bootstrap confidence intervals and an independent six-fold retraining cross-validation.

  12. 12

    regression_diagnosis

    Why the shelf-life regression is weak: train/validation/test R² and trivial-baseline checks.

  13. 13

    regression_target_triage_combined

    All three regression-target rescalings (z-score, fraction, log) trained and tested in one run.

  14. 14

    dmodel_dropout_sweep

    Capacity re-sweep of embedding size and dropout; the defaults were kept.

Reproducing this work

There are two ways in. The numbered notebooks are the original research record, each one self-contained. The scripts/ folder repeats the core pipeline (training, test evaluation, sensor-dropout robustness and significance tests) as command-line programs built on one shared package, for reruns without opening a notebook. The experiments ran in Python 3.14 with PyTorch on an Apple Silicon machine using the MPS backend; the scripts also run on CUDA and CPU. Installation steps are in INSTALL.md in the repository.

With the notebooks

  1. 1

    Get the data

    Download TR-6 from figshare and point ROOT in the notebooks to its folder.

  2. 2

    Build the manifests

    Run notebook 01 once. It writes the master manifest and the train / validation / test split.

  3. 3

    Train the model

    Run notebook 04. It trains ten seeds and saves their checkpoints, which notebooks 05–13 reuse.

  4. 4

    Run the analyses

    Run 05 to 14 in order. Running everything from a clean state reproduces the full pipeline.

With the scripts

From the repository root, after installing the requirements and placing TR-6 under data/TR-6:

python scripts/check_setup.py
python scripts/train.py --variant full --seeds 0-9
python scripts/evaluate.py --variant full
python scripts/robustness.py --variant full
bash scripts/reproduce_all.sh      # every variant, then the comparisons

Website dataset images

The sample images on the Dataset page live in assets/dataset/. To regenerate a matching sRGB and thermal sample for all twelve classes from your local copy of TR-6, run from the repository root: 

python docs/tools/export_dataset_samples.py --root ~/Desktop/Thesis/TR-6
